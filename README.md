# Pesquisa-Inova-o-Chart.js
 ## Dashboard com Chart.js

Projeto desenvolvido para praticar a criação de dashboards e gráficos utilizando JavaScript e a biblioteca Chart.js.

 ## Sobre o projeto

Este projeto consiste em uma dashboard simples desenvolvida com HTML, CSS e JavaScript, utilizando a biblioteca Chart.js para criar gráficos de forma dinâmica e visual.

O objetivo foi aprender como criar gráficos, inserir dados e trabalhar com diferentes conjuntos de informações dentro de um mesmo gráfico.
